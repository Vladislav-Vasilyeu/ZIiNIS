# NeuralTextStego

Учебное приложение для исследования текстовой стеганографии. Программа встраивает сообщение в текст-контейнер, изменяя отдельные слова, и извлекает его из созданного стеготекста.

Доступны три способа подбора замен:

- **OpenRouter Free** — облачная языковая модель через OpenRouter API.
- **Ollama** — локальная языковая модель через Ollama API.
- **Классический словарь** — детерминированная замена по встроенному набору русских словоформ.

## Возможности

- Графический интерфейс и командная строка.
- Работа с текстовыми файлами TXT и DOCX.
- Опциональное шифрование сообщения AES-256-GCM.
- Проверка целостности и точное извлечение данных из невидимого маркера.
- Локальный режим через Ollama не требует ключа облачного API.

## Быстрый старт

Требуется Python 3.10 или новее.

### Windows PowerShell

```powershell
cd NeuralTextStego
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

### macOS и Linux

```bash
cd NeuralTextStego
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### Настройка провайдера

**OpenRouter:** скопируйте `.env.example` в `.env` и задайте `OPENROUTER_API_KEY`. Ключ можно создать на [openrouter.ai/keys](https://openrouter.ai/keys). Бесплатные модели могут быть ограничены по квоте или временно недоступны.

**Ollama:** установите Ollama, скачайте модель и убедитесь, что локальный сервер запущен:

```powershell
ollama pull qwen2.5:3b
```

По умолчанию приложение обращается к Ollama по адресу `http://127.0.0.1:11434`; параметры можно переопределить в `.env`.

**Классический словарь:** дополнительная установка и сетевое подключение не требуются. Он охватывает ограниченный набор словоформ, поэтому не для каждого слова найдутся подходящие замены.

## Запуск

Запустить графический интерфейс:

```powershell
py main.py
```

Пример внедрения и извлечения через классический метод:

```powershell
py main.py --cli embed --provider classic --cover data/sample_cover.txt --secret "секрет" --out stego.txt
py main.py --cli extract --provider classic --stego stego.txt
```

Пример для локальной Ollama:

```powershell
py main.py --cli embed --provider ollama --cover data/sample_cover.txt --secret "секрет" --out stego.txt
py main.py --cli extract --provider ollama --stego stego.txt
```

Для облачного метода укажите `--provider openrouter`. При включённом пароле добавьте `--password "ваш-пароль"` при внедрении и тот же параметр при извлечении. Для других аргументов используйте `py main.py embed --help` и `py main.py extract --help`.

## Как это работает

1. Программа выбирает слова, которые можно заменить, и получает варианты от выбранного метода.
2. Выбор варианта кодирует доступные биты в видимом тексте. Число подходящих вариантов может быть меньше запрошенного, поэтому объём видимого кодирования зависит от ответа метода.
3. Полное сообщение также помещается в невидимый маркер с длиной и контрольной суммой.
4. При извлечении маркер проверяется, и сообщение восстанавливается без повторного вызова модели.

Маркер нужен для надёжного извлечения и сам по себе не является шифрованием. Без пароля его содержимое можно прочитать программно. Некоторые редакторы и системы обмена сообщениями удаляют невидимые символы, поэтому передавайте стеготекст как файл и проверьте его извлечение после сохранения.
