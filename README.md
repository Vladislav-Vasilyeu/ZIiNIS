# NeuralTextStego

Программное средство для скрытого внедрения текстовой информации в текстовые документы-контейнеры с нейросетевыми и классическими методами подбора замен.

**Курсовой проект** по дисциплине «Защита информации и надежность информационных систем»
БГТУ, кафедра информационных систем и технологий

## Возможности

- Edit-based стеганография: видимые замены слов строятся одним из трёх методов:
  - **OpenRouter Free** (`openrouter/free`) — бесплатный облачный API-маршрутизатор моделей
  - **Ollama** — локальная языковая модель, по умолчанию `qwen2.5:3b`
  - **Классический словарь** — детерминированный подбор из небольшого встроенного набора словоформ без сети и модели
- Невидимый маркер с проверкой целостности для надёжного извлечения без повторного вызова LLM
- Модели могут вернуть меньше вариантов, чем запрошено: программа использует реальные доступные варианты, снижает число видимо закодированных бит и явно сообщает об этом; полный секрет хранится в проверяемом маркере
- Асинхронная архитектура с retry и отменой операций
- Опциональное шифрование AES-256-GCM
- Поддержка TXT и DOCX
- Клиентоориентированный GUI (CustomTkinter)
- CLI для отладки и экспериментов

## Быстрый старт

```bash
cd NeuralTextStego
python -m venv .venv
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt

# Настройте ключ для облачного режима (не нужен для Ollama и классического метода)
copy .env.example .env
# Создайте API-ключ на https://openrouter.ai/keys
# и укажите OPENROUTER_API_KEY в .env.

# Для локальной модели установите Ollama с https://ollama.com/download,
# затем скачайте модель (около 1.9 GB):
ollama pull qwen2.5:3b
# По желанию проверьте её отдельно:
ollama run qwen2.5:3b

# Запуск GUI
python main.py

# CLI-пример
python main.py --cli embed --cover data/sample_cover.txt --secret "секрет" --out stego.txt --candidates 4
python main.py --cli extract --stego stego.txt --bits 96 --candidates 4

# Классический режим не требует API или Ollama
python main.py --cli embed --provider classic --cover data/sample_cover.txt --secret "секрет" --out stego_classic.txt
python main.py --cli extract --provider classic --stego stego_classic.txt --bits 96

# Локальная Ollama
python main.py --cli embed --provider ollama --cover data/sample_cover.txt --secret "секрет" --out stego_local.txt
```

### Подходит ли Qwen 2.5 3B этому ноутбуку?

Каталог Ollama указывает размер `qwen2.5:3b` около **1,9 ГБ**. На RTX 3050 Laptop с 4 ГБ видеопамяти это разумный стартовый размер; приложение ограничивает контекст 2048 токенами, чтобы оставить часть VRAM под контекст и рабочий стол. Фактическое ускорение зависит от драйвера и свободной видеопамяти. Если модель не помещается на GPU, Ollama может использовать CPU медленнее; более лёгкий запасной вариант — `qwen2.5:1.5b` (около 986 МБ). Размер модели — это не полный расход RAM/VRAM во время работы.

## Принцип работы (edit-based)

1. Секретное сообщение → битовая строка (опционально после AES).
2. В контейнере находятся слова, пригодные для замены.
3. Выбранный метод возвращает 2 или 4 кандидата: OpenRouter, локальная Ollama-модель или встроенный классический словарь.
4. Первые биты выбирают видимые замены; заменяется не более восьми слов, чтобы ограничить бесплатные API-запросы.
5. Для точного восстановления полный payload также сохраняется в невидимом маркере с длиной и контрольной суммой.
6. Извлечение читает маркер и не вызывает модель повторно, поэтому замена/обновление модели не меняет результат.

## Лицензия

Бесплатный маршрут использует только модели с нулевой стоимостью; выбранная модель меняется автоматически. Бесплатный тариф ограничен по числу запросов, а доступность отдельных моделей и скорость могут меняться. Для стабильного результата запрос требует поддержку JSON Schema. Текстовые фрагменты передаются OpenRouter и выбранному им провайдеру.
Локальная модель требует отдельной установки Ollama и загрузки модели; обработка выполняется на компьютере пользователя. Встроенный словарь содержит ограниченный набор точных русских словоформ, поэтому классический режим пропускает неизвестные словарю слова и может не найти замену в коротком тексте.
Без пароля маркер содержит исходный payload в кодировке UTF-8 и может быть извлечён программно; включите пароль, если payload не должен храниться открытым текстом. Некоторые редакторы могут удалить невидимые символы при копировании/форматировании.
